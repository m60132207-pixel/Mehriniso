# Frontend Developer Portfolio (HTML5 + CSS3)

Zamonaviy UI/UX dizayn tamoyillari (Dark Mode, Glassmorphism, Responsive Sidebar Layout) asosida yaratilgan 5 sahifali portfolio shabloni.

## Fayllar tuzilmasi
- `index.html` — Home (Bosh sahifa, Hero bo'limi, statistika va texnologiyalar steki)
- `about.html` — About (Men haqimda, texnik ko'nikmalar progress-barlari va xizmatlar)
- `resume.html` — Resume (Ish tajribasi va ta'lim xronologiyasi)
- `portfolio.html` — Portfolio (Toza CSS yordamida ishlaydigan kategoriya filtrlari va loyiha kartalari)
- `contact.html` — Contact (Aloqa ma'lumotlari va interaktiv xabar yuborish formasi)
- `css/style.css` — Barcha sahifalar uchun umumiy UI/UX stillar va mobil moslashuv (Responsive)
